# Pareceres do revisor externo

Superfície exclusiva do agente `externo` — revisor independente contratado
pelo autor, rodando em outro provedor/modelo. O valor dele é o **viés
diferente**: ele lê o mesmo texto sem a memória das decisões que o
produziram, e por isso enxerga o que a equipe interna já naturalizou.

Regras (PROTOCOLO v1.3):
- ele escreve SÓ aqui; não edita prosa, bib, fichamentos, scripts nem plano;
- parecer publicado é imutável (correção = parecer novo, como na banca);
- divergência com a banca ou com os revisores vai à fila do autor com os
  dois links — o autor arbitra (§7);
- achado que muda o trabalho de outro agente vira mensagem ao principal.
