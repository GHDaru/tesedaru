# Deep Active Learning for Named Entity Recognition

## Resumo
ICLR 2018 (Amazon/UT Austin): demonstra que a quantidade de dados rotulados para
NER com deep learning pode ser drasticamente reduzida via AL, com estratégias de
incerteza adaptadas a sequências (incl. normalização por comprimento — MNLP).
Resultado clássico: desempenho próximo do total com fração pequena dos rótulos.
(Entrada BibTeX herdada estava com autores/veículo errados — corrigida no
saneamento para ICLR 2018, Shen et al.)
